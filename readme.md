# Интернет-магазин (Django + Poetry)

Учебный проект интернет-магазина на **Django**, управляемый через **Poetry**.  
Цель — освоить Django и постепенно развивать функционал от базовой структуры до полноценного приложения.

📦 Описание проекта

Skystore — это приложение для отображения каталога товаров, их деталей и контактов магазина.
В проекте реализованы возможности:

* Просмотра списка товаров
* Просмотра подробной информации о товаре
* Создания, редактирования и удаления товаров
* Валидации данных при создании продукта через Django-формы
---

## 🚀 Реализовано
- Настроен проект Django через Poetry.  
- Создано приложение `catalog`.  
- Настроена маршрутизация для приложения.  
- Подготовлены HTML-шаблоны:
  - `product_create.html`
  - `contacts.html` 
  - `base.html`
  - `product_form.html`
  - `product_detail.html`
  - `product_list.html`
  - `product_confirm_delete.html`
- Подготовлены HTML-подшаблоны:
  - `inc_menu.html`
- Реализованы контроллеры для отображения страниц.  
- Настроена обработка данных формы в контроллере:
  - при успешной отправке формы отображается сообщение об успехе.
- Главная страница (/catalog/) — список товаров с изображением, именем и кратким описанием (до 100 символов).
- Страница контактов (/contacts/)
- Страница отдельного товара (/product/<pk>/) — полное описание и изображение конкретного товара. Возможность редактировать или удалить продукт.
- Страница создания нового товара (/catalog/create/)
- Ссылка на редактирование товара (/catalog/<pk>/product_update/)
- Ссылка на удаление товара (catalog/<pk>/delete/)

Все представления (views) были переведены с функциональных (FBV) на классовые (CBV) для улучшения читаемости, повторного использования кода и расширяемости проекта.
Используются стандартные Django-классы:

1. `ListView` — для отображения списка товаров
2. `DetailView` — для отображения детальной информации о товаре
3. `CreateView`, `UpdateView`, `DeleteView` — для работы с формами создания и редактирования товаров

Работа с формами
Добавлена форма `ProductForm`, наследуемая от `forms.ModelForm`, для создания и редактирования товаров.
Стилизация формы
Форма подключена и стилизована с использованием Bootstrap 5.

Регистрация пользователя
- Создана форма регистрации (`UserRegisterForm`), основанная на `UserCreationForm`. При успешной регистрации пользователь автоматически авторизуется.
- После регистрации пользователю отправляется приветственное письмо на электронную почту.
- Отправка писем реализована через SMTP-сервер Яндекса (настройки хранятся в `.env` для защиты чувствительных данных).

Авторизация пользователя
- Реализована форма входа (`login.html`) с использованием стандартного класса `LoginView`.
- При успешном входе пользователь перенаправляется на главную страницу каталога.
- В навигационном меню реализованы ссылки на вход и выход из аккаунта.
- Если пользователь не авторизован — отображается ссылка «Вход».
- Если пользователь авторизован — отображается ссылка «Выход» (через форму POST).

Ограничение доступа
Для ограничения доступа к страницам управления продуктами используется `LoginRequiredMixin`.
Неавторизованные пользователи не могут:
1) просматривать детальную информацию о товаре,
2) создавать, редактировать или удалять товары.
Общедоступной остаётся только страница списка товаров.
При попытке неавторизованного доступа пользователь перенаправляется на страницу входа (`/users/login/`).

## ▶️ Запуск проекта
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/username/online-store-pt.git
   cd online-store-pt
   
2. Установить зависимости через Poetry:
```
poetry install
```

3. Активировать виртуальное окружение:
```
poetry shell
```

4. Выполнить миграции:
```
python manage.py migrate
```

5. Запустить сервер разработки:
```
python manage.py runserver
```

После запуска проект будет доступен по адресу:
👉 http://127.0.0.1:8000/home/ или http://127.0.0.1:8000/contacts/
